## Cara Menjalankan

1. Pastikan **JDK** dan **NetBeans IDE** sudah terpasang.
2. Clone repositori ini:
   ```bash
   git clone https://github.com/USERNAME/praktikum-pbo.git
   ```
3. Buka NetBeans, pilih **File > Open Project**, lalu arahkan ke folder hasil clone.
4. Buka file class utama (`Main.java` atau sesuai README tiap folder), lalu klik **Run File** (Shift + F6).
